# Before/After Gallery

Visual proof for trade, landscaping, med-spa, construction.

**Layout:**
- Section H2 + 1-line lede
- 3-6 before/after pairs
- Each pair: side-by-side images OR drag-handle slider (CSS-only if possible)
- Captions below each pair: project type, location, month/year

**Rules:**
- Only use REAL project photos with owner permission
- Match lighting and angle between before/after
- Consistent aspect ratio across all pairs
- NO stock before/afters
- If fewer than 3 real pairs available, SKIP this section
- Alt text must describe what changed, not just "before" / "after"
