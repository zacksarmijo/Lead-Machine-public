# Testimonial Block

Real quoted testimonials from named clients.

**Two variants — pick based on available content:**

**Variant A — Single feature (if one strong quote):**
- Full-width section, surface background
- Large opening quote mark (decorative, accent color)
- Quote body, 30-60 words, serif or display font at 24-28px
- Attribution: "— First L., City, Project type"
- Optional small photo of client (rounded square)

**Variant B — 2-3 card grid (if multiple quotes):**
- Same as service grid but with quote + attribution
- No icons

**Rules:**
- NEVER fabricate testimonials. If no real quotes exist, SKIP this section entirely.
- Partial names and city are fine; full PII is not required
- Attribute a project/service type to make the quote relatable
- NO stock-photo faces as "customers"
