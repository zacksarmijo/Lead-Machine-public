# Service Grid (3-column)

Three primary services presented as equal-weight cards. For 6 services, use 3x2.

**Section structure:**
- Section eyebrow + section H2 centered above the grid
- Optional 1-line section lede (max 20 words)
- Grid: 3 columns desktop, 2 tablet, 1 mobile
- Gap between cards: 24-32px

**Card anatomy:**
- Icon (24-32px) at top. Line-style, single accent color. No emoji.
- Service name (H3, 18-22px, bold)
- One paragraph (2-3 sentences, 25-45 words max)
- Link: "Learn more →" (not a button — keep one primary CTA per section)

**Rules:**
- Card height equalizes to tallest card
- NO hover-flip animations
- NO "coming soon" placeholder services — omit what isn't live
